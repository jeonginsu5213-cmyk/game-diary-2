# 2026-08-18 개발 기록

## 오늘 완료한 작업

- Expo 기반 PLOG iOS 개발 앱을 실제 iPhone에 설치하고, Metro 개발 서버에 연결해 확인할 수 있게 구성했다.
- 실제 Discord 로그인 후 앱 복귀와 일기 목록 로드를 확인했다.
- 목록 화면에 실제 Discord 프로필 이미지를 표시하고, Pretendard 폰트를 적용했다.
- 목록 화면의 탭바·일기 목록·하단 검색창을 Figma 시안을 기준으로 구현했다.
- 탭바와 검색창에 유리 블러, 내부 하이라이트·음영, 외부 그림자를 추가했다.
- 검색창이 iOS 시스템 키보드 프레임 변경에 맞춰 위로 이동하도록 구현했다.

## 디자인 적용 상태

### 적용됨

- 상단 탭바의 프로필, 목록, 캘린더, 휴지통, 알림 구성
- 일기 목록의 제목·날짜·서버 아이콘 구성
- 하단 검색창의 플로팅 위치와 검색 기능
- 검색창 및 탭바의 기본 유리·그림자 효과

### 시각 확인 필요

- 탭바·검색창의 내부/외부 그림자 강도가 Figma와 같은지 실제 기기에서 비교 필요
- 키보드가 올라올 때 검색창 이동 거리와 애니메이션이 자연스러운지 확인 필요

## 미해결 항목

- 목록 카드 상단 44px 영역의 점진적 배경 흐림 효과
  - 목표: 흰색 100% → 0% 그라데이션과 점진적 배경 흐림을 하나의 효과 레이어처럼 보이게 처리
  - 현재 상태: 표준 블러·마스크 방식까지 시도했으나 Figma 결과와 동일하지 않아 현 상태로 보류
  - 주의: 다음 화면 작업에서는 이 영역을 임의로 수정하지 않는다.

## 제약 및 결정

- Figma MCP Starter 플랜의 호출 한도에 도달해, 노드별 그림자·블러 수치를 자동으로 다시 읽을 수 없다.
- 효과 수치가 필요하면 Figma Dev Mode에서 해당 효과의 값을 캡처해 수동으로 기록한다.
- 개발 기록은 `docs/plog-dev-log/`에 Markdown으로 보관하고, 코드와 같은 Git 저장소에서 관리한다.

- iOS 개발 빌드 성공
- 실제 iPhone에 개발 앱 설치 및 실행 완료
